# Protótipo de Portfólio Profissional

## 📌 Sobre o Projeto

Este projeto consiste na criação de um protótipo de portfólio profissional desenvolvido no Figma.

O objetivo é apresentar informações acadêmicas e profissionais, organizar conteúdos de forma clara e definir a navegação entre as diferentes seções do portfólio.

## 🖼️ Telas do Protótipo

### 🏠 Início

Tela inicial do portfólio com apresentação pessoal, nome, área profissional, breve descrição e acesso aos projetos.

### 👩🏻‍💻 Sobre Mim

Apresentação pessoal com informações sobre minha trajetória, interesses profissionais e dados de contato.

### 🎓 Formação e Habilidades

Apresentação da formação acadêmica e das principais habilidades técnicas e comportamentais.

### 💼 Experiência Profissional

Espaço destinado à apresentação de experiências profissionais e projetos acadêmicos desenvolvidos.

### 💻 Projetos

Seção destinada à apresentação dos principais projetos desenvolvidos.

### 📩 Contato

Tela com informações para contato e conexão profissional.
